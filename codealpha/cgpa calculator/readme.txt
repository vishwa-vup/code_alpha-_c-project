# 🎓 CGPA Calculator

A professional C++ console application that calculates a student's CGPA based on course grades and credit hours. This project demonstrates Object-Oriented Programming (OOP), STL containers, input validation, and formatted output.

---

## 📌 Project Information

- **Project Name:** CGPA Calculator
- **Language:** C++
- **Internship:** CodeAlpha C++ Programming Internship
- **Task:** Task 1 - CGPA Calculator

---

## 🚀 Features

- Add multiple courses
- Input course name, grade, and credit hours
- Automatic grade point calculation
- Calculates total credits
- Calculates overall CGPA
- Displays a formatted course report
- Input validation for grades and credit hours
- Clean and user-friendly console interface

## ⚙️ Grade Point Table

| Grade | Grade Point |
|--------|------------:|
| A | 10.0 |
| B | 8.0 |
| C | 6.0 |
| D | 4.0 |
| F | 0.0 |

---

## 📊 Formula Used

```
CGPA = Total Quality Points / Total Credit Hours
```

Where,

```
Quality Points = Grade Point × Credit Hours
```
