# 📚 Projects Included

## 🎓 Project 1 – CGPA Calculator

### Description

A C++ application that calculates a student's CGPA based on grades and credit hours.

### Features

- Add multiple courses
- Credit hour calculation
- Grade point calculation
- Total credits
- Overall CGPA
- Formatted report
- Input validation

### Concepts Used

- Classes & Objects
- Encapsulation
- STL Vector
- Functions
- Input Validation
- Formatted Output

---

## 🔐 Project 2 – Login & Registration System

### Description

A simple authentication system that allows users to register and log in using file handling.

### Features

- User Registration
- User Login
- Duplicate Username Detection
- Password Confirmation
- File Handling
- Interactive Menu
- Success/Error Messages

### Concepts Used

- Classes & Objects
- File Handling (`fstream`)
- Strings
- Loops
- Conditional Statements
- Object-Oriented Programming

---

## 🧩 Project 3 – Sudoku Solver

### Description

A Sudoku Solver that uses the Backtracking Algorithm to solve a 9×9 Sudoku puzzle automatically.

### Features

- Solves 9×9 Sudoku puzzles
- Recursive Backtracking
- Row Validation
- Column Validation
- 3×3 Grid Validation
- Displays Original Puzzle
- Displays Solved Puzzle

### Concepts Used

- Recursion
- Backtracking
- 2D Arrays
- Object-Oriented Programming
- Functions
- Algorithm Design

# ⚙️ Compilation

### CGPA Calculator

```bash

```

### Login & Registration System


